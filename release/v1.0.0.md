# Fluent Chat V1.0 - Offline Demo

First Windows x64 release of the WinUI 3 shell with a separate Rust core.

## Included
- Light and dark themes, rounded chat cards and mirrored RTL content.
- Chat search, All/Unread/Groups/Favorites filters and unread counts.
- Right-click pin/unpin, text conversations and offline message echo.
- A small emoji picker, empty-message protection and draft retention if the core request fails.
- Bounded core-process recovery and installer upgrade handshake.
- Self-contained .NET and Windows App Runtime; no separate runtime installation required.

## Important: demo only
Normal launch always enables offline demo mode with sample chats. No account is linked, and no message is sent to real people. Real-account sync, receipts, media and reconnect behavior have not been verified. This is not an official WhatsApp product.

## Downloads
- **Installer**: recommended for a normal Windows installation.
- **Portable ZIP**: extract and run FluentChat.exe.
- **Full bundle**: the original build artifact, containing the published app, portable ZIP and installer.

Builds are unsigned. Windows may show a publisher warning.

## Verified
Clean Windows 11: fresh launch/relaunch, light/dark, RTL content, search/filter counts, unread badges, pin ordering, emoji insertion, offline send/clear/echo, missing-core page, installer fresh install and upgrade over a running app, and recovery after terminating the core.

Build: https://github.com/Star-Dust-0/zapfast/actions/runs/41723023216
Runtime checks: https://github.com/Star-Dust-0/zapfast/actions/runs/41730023315

## Known limitations
New Chat, attachments, conversation search, More, older-history paging and media playback/download are not wired into the new shell. The emoji picker is intentionally small. The title bar remains LTR. Demo chat changes are not persistent across restarts.

125% display scaling, Arabic shaping, sustained animation frame rate and the full in-app update download/install path are not yet verified. The update checker targets this repository's Latest release; the installer upgrade handshake was tested separately. This release is not an all-scenarios-verified client replacement.
